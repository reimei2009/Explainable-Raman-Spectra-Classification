# Module 03: Động Lực Điện Thế và Đặc Trưng 2T2D Mở Rộng

## Mục Tiêu
Trích các chữ ký bệnh phân biệt từ động lực phổ ảnh hưởng bởi điện thế.

## Các sản phẩm đầu ra bắt buộc
- Bộ đặc trưng phản ứng điện thế
- Giao thức tạo lát 2T2D
- Các mô tả động học mở rộng vượt quá 2T2D gốc
- Nghiên cứu loại bỏ so sánh

## Nội dung các mục đề xuất
1. Tại sao động lực điện thế quan trọng trong phân tích bile SERS
2. Lựa chọn các cặp điện thế và quỹ đạo
3. Chi tiết xây dựng 2T2D
4. Các mô tả mở rộng (mẫu cường độ không đồng bộ, độ dốc, diện tích, dịch chuyển đỉnh)
5. Phân tích ổn định đặc trưng và redundancy
6. Loại bỏ so với đặc trưng tĩnh

## Danh sách kiểm tra chấp nhận
- Các đặc trưng có thể lặp lại trên mỗi mẫu.
- Đặc trưng động học vượt trội so với baseline tĩnh.
- Tính toán khả thi cho quy mô tập dữ liệu hoàn chỉnh.
- Tài liệu đặc trưng rõ ràng cho lặp lại khóa luận.

## Hành động tiếp theo sau khi phê duyệt
Triển khai API trích đặc trưng và lưu ma trận đặc trưng tiêu chuẩn hóa.
